How to use

  1. Load a vocal from the File menu, record with ●, or try the demo.
  2. Each sung note is an orange block. The line is the pitch that was sung.
  3. Drag a note up or down to change its pitch. It snaps to the key and scale; hold Alt to go in between.
  4. The knobs work on every note: Center pulls notes to the scale, Variation removes vibrato and wobble, Transition sets how fast pitch moves between notes. Drag a knob up or down, Shift for fine, double-click to reset.
  5. Space plays. Original compares with the untouched audio.
  6. Export when you're happy.

Tools (left side)

  • Select (V): move notes.
  • Cut (C): click a note to split it. Choose what cuts snap to.
  • Pitch line (P): bend the line itself, including glides between notes. Shift for fine, double-click to straighten.
  • Merge (G) joins the selected note with its neighbour. Delete removes it.

Tempo

The BPM box sets the bar and beat grid on the ruler. It doesn't change the speed of the audio.
